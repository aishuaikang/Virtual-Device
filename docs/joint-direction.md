# 联合测向模拟

入口：**侦测 → 联合测向测试**。默认关闭，开启后普通扫描改用这里的共享目标，不再使用该侦测模块的随机目标数量。解析、FPV、传统锁频测向和频谱分析保留各自原有行为。

## 连接与配置

1. 在侦测页开启“联合测向测试”。使用下方设备工具栏的“添加”增加普通侦测模块，面数不固定。每个模块配置不同的硬件 ID 和 UDP 端口。
2. 在业务后台为这些普通侦测模块填写模拟器地址、对应端口和硬件 ID，将其分配到同一模块位置，并按模拟器表格的顺序配置联合测向。模拟器里的相对角度是 `序号 × 360 / 面数`，后台安装基准角另外叠加。
3. 在后台手动开启联合测向并启动侦测，在模拟器点击“启动”。模块收到扫描命令后才开始上报；只启动模拟器、没有客户端连接时会显示“等待连接”。
4. 测试时可先关闭解析、FPV、干扰、定向打击等无关模块，方便观察共享侦测目标。默认解析硬件 ID 为 `3000`，已有场景中的硬件 ID 不会被替换。

## 上报数据

- 每个模拟目标配置型号、逗号分隔的跳频列表和每面的 RSSI；支持多个目标，跳频间隔对所有目标生效。
- 各模块使用同一个启动时间计算当前跳频位置，逐面叠加不超过 `0.6 MHz` 的接收频差。RSSI 在配置值附近小幅波动（不超过 `0.4 dB`）。默认跳频为 `5800,5803,5798,5806 MHz`，默认间隔 `1500 ms`。
- 每轮扫描都发送该模块能侦测到的所有目标，**每个目标一条 UDP 报文**。只发送 `device、model、freq、rssi、seq`，没有目标唯一 ID，也不直接发送角度。`device` 是硬件 ID，`seq` 仅在本模块内递增。
- 目标是否合并、输出哪个角度，由业务后端使用真实的“同型号＋相近频点”规则决定。修改跳频列表，既可测试阈值范围内的跳频合并，也可测试跨越阈值后的不同目标。不要把跨频段跳频预期为始终属于同一个目标。
- 表格下方的“当前最强面”是配置参考，不代表后端已经完成确认。没有上报该目标的面不参与参考值计算。

例如六面均匀部署、后台基准角为 `0°`，将硬件 `2002` 对应面的 RSSI 设置为 `-40 dBm`，其他面低于 `-50 dBm`，则它的参考相对角度为 `120°`。

## 常用测试

预设只作用于当前选中的模拟目标；也可逐面手动修改 RSSI 或“上报目标”开关。

| 操作 | 模拟行为 |
| --- | --- |
| 全部面 | 各面都上报，按当前最强面的方向生成明显的 RSSI 差异 |
| 缺两面 | 两个较弱面停止上报此目标，其他面继续上报；至少三个启用模块时可用 |
| 仅最强面 | 仅最强面上报，用于验证单面结果 |
| 强度接近 | 各面 RSSI 接近，用于观察确认和旧角度保持 |
| 全部停报 | 当前目标在所有面停止上报，在线模块继续发送心跳 |
| 关闭“启用此设备” | 整个模块不启动，可与缺少某个目标的场景对比 |
| 在业务后台对某面开启频谱分析 | 该面仅发送频谱帧和心跳，其他模块继续普通侦测；结束频谱后恢复共享目标 |

## 运行中调强度

启动后可直接修改表格中的 RSSI、逐面上报开关和测试预设，新配置在下一轮扫描生效，不需要停止或重连，跳频进度和 `seq` 继续递增。型号、跳频列表、间隔、模块数量、端口与硬件 ID 仍需停止后修改。

信号强度雷达图按模块数量自动生成，节点和表格都显示模块硬件 ID，`0°` 朝上、角度顺时针增加。外圈为 `0 dBm`，中心为 `-140 dBm`。拖动节点沿对应轴调整强度，表格会同步更新：

- 默认开启“各面联动”，拖动的面成为最强面，其他面按圆周角差平滑衰减，正对面的衰减为 `45 dB`。这只是方便测试的信号分布，不代表真实天线方向图或测向结果。
- 关闭联动后仅改变被拖动面的强度。表格输入始终逐面独立调整。
- 停报或未启用的面不显示信号节点，联动不会将停报面自动恢复。可在表格打开上报开关。
- 节点支持键盘方向键每次调整 `1 dB`，按住 Shift 为 `5 dB`，Home/End 为强度上下限。

场景保存、导入和导出会保留当前联合测向配置。修改硬件 ID、增加或删除模块会同步目标的逐面配置；硬件 ID 不可重复。

联合测向测试不主动发送锁频或切射频命令。它响应业务后台的普通扫描命令；收到传统锁频命令时仍使用原有模拟逻辑，便于从日志检查后台是否错误进入了锁频流程。
