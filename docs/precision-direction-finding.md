# 精准测向接收机模拟

模拟器按《接收机开发手册 v0.22》提供指令和数据双 TCP 连接，可直接连接现有精准测向模块。无需启动厂商 DFServer；模拟器直接生成成品方位数据，便于验证应用流程。

## 使用

1. 在模拟器左侧展开“精准测向模拟器”并启用。默认监听 `0.0.0.0`，指令端口 `10087`，数据端口 `10088`。
2. 按需设置数据间隔、天线参考角、峰值电平及质量，然后点击“启动模拟”。新模块默认关闭，旧场景不会自动开启监听。
3. 在平台的模块管理中添加“精准测向模块”。同机调试填写 `127.0.0.1:10087`；跨机器填写运行模拟器的机器 IP 和指令端口，并开放两个 TCP 端口。`0.0.0.0` 是监听地址，不能作为远端设备地址。
4. 从模块操作列进入“测向操作”，选择单频测向、实时频谱扫描或定频 IQ 采集。定频 IQ 使用 FFM 模式，仅需中心频率、带宽、点数及单包/重复单包设置，无需登记天线码。
5. 右侧显示双连接状态、当前模式、设备 TASK、最近指令和累计数据量。停止平台任务发送 `ABOR`，停止模拟会关闭两个连接；平台可验证中断和重连流程。

## 模拟范围

| 功能 | 行为 |
| --- | --- |
| SFDF | 按请求频率、FFT 点数和带宽输出频谱及单频方位，支持单次/连续 |
| PSCAN2 | 实时频谱扫描。以带宽对应采样率和 FFT 点数计算分辨率，端点向外对齐到扫描网格，每 256 点分段输出频谱。连续/单次业务类型为 `0x91`/`0x90`，单次完整扫描后结束，不生成测向方位 |
| FFM IQ | 定频 IQ 采集。固定请求中心频率与带宽输出小端交错 int16 I/Q；SINGLE/REPEAT 业务类型为 `0x10`/`0x13`。一包最多设置 512458752 点，但每帧只生成最多 4096 对；单包完成后停止，重复单包之间保留模拟调度间隔。不轮换天线，不解算方位 |
| 旧客户端兼容 | 保留 SCANDF 扫描测向及 DFCAP A/B 逐天线 IQ 协议供既有客户端调试；新的平台操作界面不再提供这些任务 |
| 射频配置 | 接受 NORMAL/LOWNOISE/LOWDIST；RFAT 和 IFAT 会降低生成的电平 |
| GNSS / RAWGNSS | 开关控制约每秒输出的定位和 NMEA，位置取全局中心点 |
| 触发 | 接受现有客户端的时间、电平和 GPIO 触发配置；电平/GPIO 自动满足条件，时间触发按本机时钟及数据间隔近似调度 |
| 无效角 | 参考角设为 `-1`；扫描中低于电平门限的频点也返回 `-1` |
| 链路 | 二进制封装、大小端、DATA_AT_PORT、TASK、拆包粘包、停止及重连 |

每个模拟接收机只接收一组平台指令/数据连接，额外连接会被关闭。扫描最多 100 万点，超出时明确返回错误。频谱和方位是可复现的生成数据，质量值不是角度精度；IQ 是测试正弦波，不包含真实射频信号。天线切换等待、外部电气触发、射频硬件模式和厂商测向算法不作物理仿真；时间戳来自本机，不能验证 GNSS 授时精度或 TDOA。

## 验证

```bash
go test ./...
go test -tags=integration -race ./...
cd frontend && bun run build
```

协议测试检查实际命令字节和数据字段偏移；TCP 集成测试覆盖 PSCAN2 扫描分段及频率对齐、FFM 单包/重复 IQ、最大 IQ 点数的有界输出及停止后切换任务，并保留旧协议无效角、GNSS、IQ 天线与频率遍历、任务号隔离、停止、断线重连及单控制端限制。真实硬件行为仍需实机验收。
